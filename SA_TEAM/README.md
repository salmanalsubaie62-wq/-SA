# SA TEAM — المؤسسة الذكية

النظام التشغيلي لمؤسسة افتراضية فيها ٣٠ موظف ذكاء اصطناعي. المؤسس هو صاحب القرار النهائي، ورامي يدير ويوزع.

## وين تلقى كل شي

| المجلد | وش فيه |
|---|---|
| `MANAGEMENT/` | الدستور (القواعد العليا)، دليل رامي، وأدوات الإدارة (`tools/`) |
| `EMPLOYEES/` | بطاقات الموظفين الثلاثين + `ROSTER.md` |
| `WORKFLOWS/` | أنظمة العمل: تنفيذ المهام، المشاريع، الاجتماعات، الصراحة، التوظيف، خطوط الإنتاج، الجودة، التقارير، الأوامر، المكتب الافتراضي |
| `TEMPLATES/` | قوالب: ملف مشروع، حالة، توزيع مهمة، محضر اجتماع، تقرير، بطاقة موظف، تقييم نقدي |
| `PROJECTS/` | كل مشروع في مجلد مستقل |
| `SKILLS/sa-team/` | سكل الاستدعاء (نفس اللي يتحفظ في Claude) |
| `REPORTS/` | تقارير المؤسسة، ومنها تقرير البناء |
| `PORTFOLIO/` | أعمال العرض للعملاء |
| `ARCHIVE/` | المشاريع المنتهية |

## التشغيل في Claude Code

1. حط مجلد `SA_TEAM` في جهازك، وافتح Claude Code داخله.
2. انسخ `SKILLS/sa-team` إلى `~/.claude/skills/sa-team` (أو احفظ السكل من claude.ai).
3. جرّب:
   - `يا رامي، حالة المؤسسة`
   - `ابدأ مشروع: موقع منيو لمطعم`
   - `اجتماع: نسعّر خدمة مواقع 3D`

## أدوات الإدارة (تشتغل فعلياً)

```bash
python3 MANAGEMENT/tools/new_project.py "اسم-المشروع"   # يفتح مشروع جديد من القوالب
python3 MANAGEMENT/tools/status.py                      # حالة كل المشاريع من ملفات STATUS.md
```
