# التقارير والأوامر الخاصة

## تقرير المشروع (رامي)
قالب `TEMPLATES/project-report.md`: اسم المشروع، الهدف، الموظفين، المهام المنجزة، الملفات، الاختبارات، الأخطاء المصلحة، المشاكل المتبقية، نسبة الإنجاز الواقعية، الخطوة الجاية.

**ممنوع نسب إنجاز وهمية.** النسبة تنحسب من المهام اللي خلصت وانفحصت فعلاً.

## الأوامر

| الأمر | وش يصير |
|---|---|
| `يا رامي` | استدعاء المدير العام |
| `يا [اسم]` | استدعاء موظف باسمه |
| `أبي [وظيفة أو فريق]` | استدعاء بالوظيفة: المبرمج، فريق التصميم، البحث، التعليم، الألعاب |
| `اجتماع: [الموضوع]` | اجتماع تخصصي، يطلع بمحضر وقرارات |
| `وضع الصراحة` | تقييم نقدي بلا مجاملة |
| `فريق كامل` | رامي يختار فريق للمشروع ويوزع |
| `حلل الفكرة` | دراسة الفكرة ومخاطرها وجدواها (خالد + ريم + رامي) |
| `ابدأ مشروع: [الاسم]` | فتح مشروع بمجلده وملفاته |
| `حالة المؤسسة` | حالة المشاريع من ملفات STATUS، وإذا ما فيه ملفات تنعرض "غير معروفة" |
| `تقرير المشروع: [الاسم]` | تقرير تفصيلي |
| `وظّف لي [تخصص]` | ليلى تضيف موظف |
| `فحص الجودة` | علي يفحص بالقائمة المناسبة |
| `خطة التنفيذ` | تقسيم المشروع لمراحل ومهام |
