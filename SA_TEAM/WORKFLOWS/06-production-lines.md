# خطوط الإنتاج

أي مجال جديد يتكرر يتحول لخط إنتاج بنفس الشكل.

---

## 1. المواقع والمنيوهات (QR وصفحات الهبوط)
- **الفريق:** حمد ← روان ← هيا ← عمر ← علي ← شهد
- **المدخلات:** اسم المحل، الشعار، المنيو أو المنتجات، الأسعار، الصور، وسيلة الطلب
- **الخطوات:** المتطلبات ← الهوية (`b`) ← التصميم والبناء (`f` `n` `l`) ← المراجعة (`r`) ← رمز QR ← التسليم
- **المخرج:** موقع منشور + رمز QR + ملفات المصدر
- **الجودة:** قائمة المواقع في `07-quality.md`
- **الوقت المتوقع:** يوم إلى يومين
- **الأدوات:** HTML/CSS/JS، الاستضافة

## 2. مواقع 3D
- **الفريق:** روان ← هيا ← وليد + عمر ← علي
- **المدخلات:** البراند، المنتج، الصور أو المجسمات، الرسالة
- **الخطوات:** الفكرة بجملة (`n`) ← المشهد 3D ← المحتوى ← الأداء على الجوال ← المراجعة
- **المخرج:** موقع 3D يشتغل، مع بديل للأجهزة اللي ما تدعم WebGL
- **الجودة:** قائمة المواقع + سلاسة الحركة (٦٠ إطار على الجوال المتوسط)
- **الوقت المتوقع:** ٣ إلى ٧ أيام
- **الأدوات:** Three.js

## 3. الإعلانات والفيديوهات
- **الفريق:** مريم ← نواف ← عبدالله ← زياد ← علي
- **المدخلات:** المنتج، صوره، الجمهور، المنصة، المدة
- **الخطوات:** السيناريو ← قائمة اللقطات ← توليد الصور والفيديو ← التعليق ← المونتاج ← التصدير
- **المخرج:** فيديو بالمقاسات المطلوبة
- **الجودة:** قائمة الفيديو
- **الوقت المتوقع:** يوم إلى ٣ أيام
- **الأدوات:** أدوات التوليد المتاحة فعلاً (مثل ElevenLabs إذا مربوط)، ffmpeg
- **تنبيه:** التوليد يصرف رصيد، فرامي ياخذ موافقة المؤسس قبل الفيديوهات الطويلة.

## 4. إعلانات UGC
- **الفريق:** مشاري ← جود ← عبدالله ← زياد
- **المدخلات:** المنتج، الجمهور، الزاوية
- **الخطوات:** سكربت طبيعي ← لقطات ← صوت ← مونتاج
- **المخرج:** إعلان قصير ٩:١٦
- **الجودة:** قائمة الفيديو، وما نعرض الإعلان المولد كتجربة عميل حقيقية
- **الوقت المتوقع:** يوم
- **الأدوات:** أدوات الصور والفيديو والصوت المتاحة

## 5. المواقع التعليمية والتحضير المدرسي
- **الفريق:** منيرة ← عمر أو جاسم ← علي
- **المدخلات:** المادة، الصف، اسم الدرس، الفصل الدراسي
- **الخطوات:** التحضير بالصيغة المعتمدة ← الأنشطة والتقويم ← الموقع التفاعلي ← المراجعة
- **المخرج:** تحضير + ورقة عمل بالإجابات + موقع درس
- **الجودة:** قائمة المحتوى التعليمي
- **الوقت المتوقع:** نص يوم إلى يومين
- **الأدوات:** Docs أو Word، HTML

## 6. الألعاب
- **الفريق:** جاسم ← هيا ← عبدالله ← علي
- **المدخلات:** الفكرة، الجمهور، المنصة
- **الخطوات:** خطة اللعبة (`gp`) ← أول نسخة تنلعب (`gw`) ← الفن والصوت ← الاختبار ← المراحل
- **المخرج:** لعبة متصفح تنلعب
- **الجودة:** قائمة الألعاب
- **الوقت المتوقع:** حسب الحجم، أول نسخة تنلعب خلال يومين
- **الأدوات:** Phaser، Three.js، canvas
