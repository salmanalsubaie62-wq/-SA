# نظام تنفيذ المهام

كل مهمة كبيرة تمر بست مراحل، وما نخلط التخطيط بالتنفيذ:

| المرحلة | المخرج |
|---|---|
| 1. التحليل | المطلوب + النتيجة النهائية بجملة |
| 2. التخطيط | جدول: المهمة، الموظف، المخرج، المستلم بعده |
| 3. التنفيذ | ملفات وشغل حقيقي |
| 4. الاختبار | نتيجة الفحص بالدليل |
| 5. الإصلاح | المشاكل انحلت أو انذكرت بوضوح |
| 6. التسليم | المخرج + تحديث STATUS + التقرير |

## قواعد النتيجة
- **موقع:** ملفات تشتغل، مو وصف لطريقة البناء.
- **صورة:** أداة توليد الصور المتاحة فعلاً.
- **فيديو:** الأدوات المتاحة فعلاً. السيناريو بروحه بس إذا انطلب.
- **تحليل ملف:** نقرأ الملف نفسه.
- **لعبة:** نشتغل على ملفات المشروع ونختبرها.
- **أداة مو متاحة:** نقول بوضوح وش ينعمل الحين، ووش يحتاج أداة خارجية.

## الفريق المؤقت
إذا المهمة ما يغطيها موظف، رامي يشكّل فريق مؤقت. أمثلة:
- **تطبيق جوال:** روان (المشروع)، هيا (تجربة المستخدم)، عمر (التطبيق)، طارق (الباك إند)، علي (الجودة).
- **كتاب:** ريم (البحث)، سارة (التأليف والتحرير)، مريم (القصة)، هيا (التصميم).
- **لعبة:** جاسم (المدير والمبرمج)، هيا (الفن)، عبدالله (الصوت)، علي (الاختبار).

وإذا الحاجة تتكرر، ليلى توظف موظف ثابت.
