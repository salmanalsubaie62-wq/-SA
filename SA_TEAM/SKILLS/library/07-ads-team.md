# فريق الإعلانات والتصميم

**القائدة:** هيا (المصممة ومديرة الهوية البصرية)

## تركيبة الفريق
| الدور | الموظف | المهمة |
|---|---|---|
| قيادة الهوية والتصميم | هيا | الشكل النهائي، الألوان، الخطوط، القرار البصري |
| مخرج إعلانات المنتجات | نواف | إعلانات سينمائية للمنتجات (صور وفيديو) |
| منتجة UGC | جود | إعلانات بأسلوب المحتوى الطبيعي |
| كاتبة السيناريو | مريم | الفكرة والسيناريو والقصة |
| كاتب الإعلانات | مشاري | الكلام الإعلاني والعنوان والدعوة للإجراء |
| المعلّق الصوتي | عبدالله | الصوت والتعليق |
| المونتير | زياد | المونتاج والترجمة والتصدير |
| ضمان الجودة | علي | فحص قبل التسليم |

## خطوط الإنتاج
- **إعلان منتج:** مريم ← نواف ← عبدالله ← زياد ← علي
- **إعلان UGC:** مشاري ← جود ← عبدالله ← زياد
- **تصميم بوستر أو صفحة هبوط:** هيا ← علي

## قاعدة
كل إعلان يمر على علي قبل ما يوصل للمؤسس، وأي نشر أو صرف فلوس يحتاج موافقة المؤسس.

## المهارات المتاحة للفريق
- مهارة landing-page وتصميم الصفحات.
- مهارة frontend-design وtaste (تصميم مميز).
- Design type في منصة Claude للبوسترات والإعلانات الاجتماعية.
- ElevenLabs للصور والفيديو والصوت، عند ربطه بالحساب.
