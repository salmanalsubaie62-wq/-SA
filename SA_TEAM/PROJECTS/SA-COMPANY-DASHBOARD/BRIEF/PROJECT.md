# SA-COMPANY-DASHBOARD — ملف المشروع

- **الاسم:** SA-COMPANY-DASHBOARD
- **تاريخ البدء:** 2026-11-19
- **الوصف:** موقع ويب داخلي يعرض كل تقارير الموظفين اليومية، ويعرض الإيرادات، وكل شي يخص المؤسسة (الموظفين، المشاريع، الحالة).
- **الهدف (النتيجة النهائية بجملة):** المؤسس يفتح الموقع ويشوف تقرير أي يوم، وإيرادات المؤسسة، وحالة الموظفين والمشاريع، بدون ما يفتح الملفات يدوياً.
- **المجال:** لوحة متابعة داخلية (تقارير، مالية، حالة المؤسسة)
- **العميل / لمن:** المؤسس
- **الملفات المرجعية:** `SA_TEAM/REPORTS/YYYY-MM-DD/` (تقارير الموظفين)، `SA_TEAM/PROJECTS/*/STATUS.md` (حالة المشاريع)، `SA_TEAM/EMPLOYEES/` (بطاقات الموظفين)
- **الموظفين المسؤولين:** رامي (إدارة وتسليم)، روان (المتطلبات ومتابعة STATUS)، عمر (بناء الواجهة)، راشد (سكربت تجميع البيانات من الملفات)، هيا (التصميم والهوية)، علي (فحص الجودة قبل التسليم)
- **القيود (وقت، ميزانية، أدوات):**
  - ملفات فقط بدون خادم أو قاعدة بيانات: الموقع ثابت (HTML/CSS/JS) يقرأ ملفات JSON يولّدها سكربت.
  - بيانات الإيرادات غير موجودة في أي ملف حالياً. ما ننشر أرقام مخترعة، والقسم يعرض "لا توجد بيانات" حتى يُزوَّد بالأرقام.
  - تشغيل مجاني: بدون اشتراكات أو مكتبات خارجية من الإنترنت.
