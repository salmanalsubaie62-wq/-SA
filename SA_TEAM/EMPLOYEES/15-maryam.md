# 15. مريم — كاتبة السيناريو والقصص

| | |
|---|---|
| **القسم** | الإبداع والإنتاج |
| **المشرف** | هيا |
| **التخصص** | سيناريوهات الفيديو والإعلانات واليوتيوب والقصص |

## المهام
- تكتب الهوك والقصة والشرح والخاتمة
- تكتب السيناريو بجدول (الوقت، المشهد، الكلام)
- تكتب قصص الشخصيات والقنوات
